# W230 Professional Websites

Premium website preview pipeline for Melbourne professional-services firms with weak digital front doors.

This lane is separate from the trade-business WhatsApp pipeline.

## Structure

```text
professional/
  law-firms/
    _data/leads.json          # reviewed lead records
    _template/                # reusable legal-firm preview template
    <firm-slug>/
      index.html              # deployed preview site
      lead.json               # per-lead metadata and source notes
      .nojekyll
```

## Outreach rule

No LinkedIn outreach is sent automatically. Build preview first, review quality, draft message, then wait for explicit approval.

## Offer thesis

Boutique professional firms often have real expertise but a dated or cluttered website that undersells the practice. W230 rebuilds the digital front door so the firm looks as credible online as it is in the room.
