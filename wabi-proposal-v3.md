# Proactive App Seeding Pilot for Wabi

**A 3-week activation experiment to reduce Wabi's education gap through direct utility.**

---

## Hypothesis

> Seeded mini apps delivered directly to target users will increase activation (measured as core-action completion within 24 hours of link open) by at least 2x vs baseline organic acquisition, and produce measurable early retention signal at D7.

Falsifiable. If seeded users don't activate at 2x baseline within week 3, the mechanic doesn't work at current scale.

---

## The Problem

Wabi's users arrive at the platform and don't know what to do. The current model asks them to:

1. Understand what a "mini app" is
2. Imagine what they could build
3. Create it from scratch

That's three cognitive steps before any value is experienced. Most users drop before step one.

**Paul identified this directly:** the education gap is the #1 blocker. People don't return because they never experienced value in the first place.

---

## The Mechanic

Flip the funnel. Don't teach users what mini apps are. Drop a working solution in their lap and let usage teach the concept.

```
Current:  Arrive → Understand → Imagine → Create → Use (maybe)
Seeded:   Receive → Use → Understand → Create (organic)
```

**This is not replacing user creation.** It's the acquisition layer that feeds it. Seeded user → experiences value → "I could make one of these" → becomes creator.

The same mechanic I've tested in another vertical: identify businesses with no website, build one, send them a preview. Conversion is dramatically higher than "come browse our platform." The principle maps directly.

### Week-by-Week

**Week 1: Validate & Build**
- Confirm 3-5 target segments with Wabi data
- Define core actions and "first value" per app
- Build 10-12 apps, QA, instrument events
- Generate tracked links per segment/channel

**Week 2: Distribute**
- Ship to target segments across 2-3 channels
- Monitor activation in real-time
- Iterate on friction points (link flow, app clarity)

**Week 3: Measure & Report**
- Activation rate vs baseline (the primary metric)
- D7 retention signal (cohort-based, not aggregate)
- Remix/build rate (creator conversion)
- Segment-channel breakdown (what works where)
- Scale recommendation: go / no-go / pivot

## Metrics (AARRR Framework)

### Activation (primary — this pilot)
- **Core-action completion rate** within 24h of link open
- **Time to first value** (TTFV): app open → core action complete
- **Second session within 72h** (early stickiness signal)

### Retention (observed, not guaranteed in 3 weeks)
- **D7 cohort retention**: % of activated users returning
- **D14 retention**: instrument now, read week 5-6
- **D30 retention**: instrument now, read week 7-8

### Expansion (secondary signal)
- **Remix/build rate**: % of activated users who create within 14 days
- **Share rate**: forwarded links from seeded users (viral proxy)
- **Template copy rate**: if the system supports cloning

## Where This Goes (If Activation Works)

The pilot tests stage one of a three-stage growth engine:

**Stage 1 (this pilot): Seeded activation**
Deliver working apps to target users. Prove they activate at higher rates than organic.

**Stage 2: Proactive adaptation**
Apps aren't static. They observe usage patterns and adapt — layout shifts, features surface, content refreshes. The user didn't ask. It just got better. That's the magic moment that drives return visits.

**Stage 3: Anticipatory generation**
AI observes what the user almost needs next and generates a new app before they ask. Now the user has a growing personal software ecosystem. Each app adds context, making the next one more relevant. The platform becomes increasingly personal and increasingly hard to leave.

**Why this is structurally impossible on YouTube:**
YouTube recommends the next video. But the video you watched yesterday can't get better today. On Wabi, the app you used yesterday can wake up smarter tomorrow. That's not a feature. That's a different category of product.

The pilot proves or disproves stage one. Stages 2-3 are the strategic upside, not the scope of this engagement.
